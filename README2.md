# Exercício GitHub

Este projeto foi desenvolvido como um exercicio de avaliação na unidade de GitHub.
Tem como objetivo a prática da criação, organização e utilização de um repositório no GitHub.

## Sobre o projeto:
Este projeto foi proposto na uala de GitHub e tem como objetivo praticar a utilização de um repositório, a organização de ficheiros e a documentação através do Markdown.

### Ficheiros do projeto
- README2.md
- Sobre-mim-txt
- lista-tarefas.txt

## Tecnologias Utilizadas 
| Tecnologia | Utilização | 
|:----------:|:----------:|
| Git | Controlo de versões |
| GitHub | Repositório remoto |
| Markdown | Documentação | 

## Como utilizar 

1. Aceder ao repoditório no GitHub.
2. Consultar os ficheiros disponivéis.
3. Visualizar e editar os ficheiros conforme necessário.

## Exemplo de código 

``` 
git status
```
